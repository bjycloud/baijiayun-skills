# 百家云 API 错误码参考

## 通用错误码

| code | 说明 | 解决方案 |
|------|------|---------|
| 0 | 成功 | - |
| 1 | 普通错误 | 查看 msg 字段获取具体错误原因 |
| 404 | 请求路径不存在 | 检查 API 地址是否正确 |
| 1001 | 参数错误 | 检查必填参数是否完整，参数格式是否正确 |
| 1002 | 签名计算错误 | 检查 partner_id / partner_key 是否正确，签名算法是否符合规范 |
| 2001 | 账号不存在 | 检查 partner_id 是否正确 |
| 2002 | 账号权限错误 | 检查账号是否开通了对应的功能权限 |
| 2003 | 直播账号未开或服务停止 | 检查账号状态，确认服务是否正常 |
| 3001 | 房间号不存在 | 检查 room_id 是否正确 |
| 3002 | 该房间已删除 | 房间已被删除，无需重复操作 |
| 4001 | 文件上传失败 | 请稍后重试 |

## 创建房间特殊限制

| 限制 | 说明 |
|------|------|
| 调用频率 | 单账号单 IP 10 秒内请求不超过 200 次 |
| 创建频率 | 24 小时内调用次数不超过 5000 次 |
| 房间时长 | 普通房间开始和结束时间间隔需大于 15 分钟并小于 24 小时 |
| 时间范围 | 开始和结束时间必须在当前时间一年以内 |
| 标题长度 | 不超过 50 个字符或汉字 |

## 权限相关

需要联系百家云客服开通的权限：

- 长期房间创建权限（`is_long_term=1`）
- 伪直播功能
- 推流直播功能
- 双师课功能
- 分组课堂功能
- 研讨会模式（`new_group_live=2`）
